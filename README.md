# Control de Recorridos de Limpieza — Versión Profesional

## Publicación en GitHub Pages
1. Descomprime el ZIP.
2. Sube todos los archivos directamente a la raíz del repositorio.
3. Reemplaza los archivos anteriores cuando GitHub lo solicite.
4. Espera 1–3 minutos y abre la página.
5. Si ves la versión anterior, presiona Ctrl + F5.

## Archivos principales
- index.html
- styles.css
- app.js
- supabase-config.js

La base de datos y los usuarios existentes se conservan. Esta actualización modifica principalmente diseño, navegación y experiencia de uso.
